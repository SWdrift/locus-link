# 0.2.0 CLI 迁移

`0.2.0` 从 `0.1.0` 执行 CLI clean cutover；`locus/v1` Registry 与 State schema 1 不变，不需要 State migration。

- Resolve 使用 `locus resolve <target> <capability>`；`--capability` 已删除。
- 用户 Registry 使用 `locus init --user --scope-id <id>`；`user init` 已删除。
- 本机 UI 使用 `locus ui`；`web` 已删除。
- Resolve、Probe 和指定对象的 Status 默认从声明首条 Link 推导 origin；`--from` 是显式断言。
- Context 和汇总 Status 不要求 `--from`。
- 旧命令、旧 flag、别名和转换路径均不存在；Cobra 按标准 unknown command/flag 处理。
