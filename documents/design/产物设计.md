# locus-link 产物设计

## 简述

locus-link 提供两个 Windows executable：完整产物内嵌 Web UI，后端产物保留同一 CLI 与 Web API、但不包含页面资源。两者复用同一个 Core 和 `/api/v0` 契约。

## 职责

本文是产物组成、构建依赖和用途的权威说明；脚本用法见 [`scripts/README.md`](../../scripts/README.md)，CLI 与 HTTP 行为分别见[CLI 契约](contracts/CLI契约.md)和[本机 Web 契约](contracts/Web契约.md)。

## 产物

| 产物 | 组成 | 构建入口 | 用途 |
| --- | --- | --- | --- |
| `temp/bin/locus.exe` | Core、CLI、Web API、内嵌 Web UI | `scripts/build.ps1` | 最终交付与内嵌页面调试 |
| `temp/bin/locus-backend.exe` | Core、CLI、Web API | `scripts/build-backend.ps1` | CLI 使用及前后端分离开发 |

完整产物先生成 `internal/web/ui/dist/`，再将其嵌入 executable。后端产物不导入页面资源、不要求 `dist/`，也不调用 pnpm；其非 API 页面路径返回 `404`。

## 开发组合

分离开发分别运行 `scripts/start-web-api.ps1` 与 `scripts/start-web-ui.ps1`：Go API 固定监听 `127.0.0.1:7070`，Vite 固定监听 `127.0.0.1:5173` 并代理 `/api`。最终形态由 `scripts/start-web.ps1` 构建并启动，只运行完整 executable。

两种 Go 启动入口复用 `temp/e2e-run/` 的 Project Alpha fixture；fixture 缺失时先运行 `scripts/test-e2e.ps1`。
